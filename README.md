# MCW01
## Polaroid 110A/B 4X5 Conversion

This is an archive of past releases of the MCW01 Polaroid 4x5 Conversion Kit. 

My website acts as a living document to host the most up-to-date version of the kit with install instructions.

[milchlingcameraworks.com](milchlingcameraworks.com)

## Overview
  The MCW01 is a 4x5 conversion for Polaroid 110 and 110B cameras, compatible with both graflok and standard two-sided film holders. It has centered framing and full 4x5 coverage. 

  All versions of my kit to date utilize the same modifications to the camera chassis and are interchangeable on the same camera, including the MCW02 medium format conversion. The individual        components of each rev have varying levels of compatibility due to the changes to hardware. Rev E is the culmination of efforts to simplify printing/assembly, improve the user experience, and     expand compatibility.

  If you purchased a kit from me, I've kept a log of all kits shipped including which have received upgrade kits. If you have any questions regarding which version you received or would like a      backup copy of the exact parts you received, please email me.

  The most current revision, Rev F, is a large modification to the film holder for compatibily and improved function. The width of the graflok slides and related components have been shortened to   give better     access to   the 110A viewfinder. However, if you are adapting this design into a different platform or custom camera, rev E may be of more use to you.

## Revision Log
  Rev A – Initial Release/prototype

  Rev B - Updated photos and assembly drawings

  Rev C - Added ground glass holder and associated parts to BOM, added additional alternate bottom plate for 110A models, revised assembly drawings

  Rev D - Changed from heatserts to self tapping plastic screws for all M3 fasteners to simplify and reduce hardware count/assembly. Updated ground glass holder. Revised light seals to 1/4" x       1/16" foam strips.

  Rev E - Added alternate configuration to use standard two sided film holders in addition to the graflok compatible backs. Updated the graflok spring hardware to use m3 shoulder bolts for a        fixed spring compression. Minor changes to ground glass holder to eliminate need for spacers and special hardware, added page 7
  with visual depictions of optional bottom plate and side grip

  Rev F - Updated graflok slide design to a narrower profile for better clearance/compatibility with the 110A viewfinder. This update required changes to the upper chassis, graflok adapters,        retainers, springs, and bottom plate.
